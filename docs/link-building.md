# Getting links to AniLumi

Pages are fast, honest and well linked inside the site now. What a new site lacks for top-3 rankings is other
sites pointing at it. This is the plan for earning those links, using pages AniLumi already has. Do it by hand,
as yourself: no paid links, link swaps or posting the same thing in many places (Google treats those as spam).

## What people actually link to

| Page type | Why someone links it | Example |
|---|---|---|
| Release countdown + embed | Fan sites and Discord servers want a live "next episode" box | `/anime/<slug>` → "Embed this countdown" |
| Watch orders | Answers the question every newcomer asks in a fan community | `/watch-order/<franchise>` |
| Hindi dub guides | Few sites track which seasons have Hindi, and on which service | `/hindi-dub`, `/hi/anime/<slug>` |
| Filler lists + arcs | Long shows (One Piece, Naruto, Bleach) get this question daily | `/filler-lists` |
| Schedule / tonight | Weekly episode threads link a schedule | `/schedule`, `/tonight` |
| Data pages (drop rates, trends) | Writers and YouTubers quote numbers with a source | `/trends`, an anime page's "Stats" |

## Weekly routine (about 2 hours)

1. **Answer 3-5 real questions** ("what order do I watch X", "is X on a break", "where to watch X in Hindi") on
   Reddit, Quora or Discord. Write the answer in the post itself and add the AniLumi page as the source. Read each
   community's self-promotion rules first; many allow a link only as a source or in a weekly thread.
2. **Offer the embed to 2-3 fan sites or Discord servers** for a show that's airing (template below).
3. **Share one of your own takes**: your view of the season, a ranking, a "what to watch after X" list, linking
   the pages you used. Your own opinion is what gets shared; a bare link is not.
4. **Note what got clicks** (GA4 → Acquisition → referrals) and do more of that.

## One-time listings

- Your own profiles: harshlariya.in project list, LinkedIn, GitHub profile README, X/Instagram bio.
- Directories and lists of anime tools/sites that accept submissions (check each one is a real site with
  traffic, not a link farm).
- Product Hunt / Indie Hackers launch post about how the site was built (the AniList/Kitsu data, the alerts).

## Embed offer template

> Hi! I run AniLumi (anilumi.in), a free anime guide. I made a small countdown box for **<show>** that shows
> the next episode's time in the visitor's own timezone and updates itself every week, including breaks
> (like One Piece's, back on 3 January). If it's useful for your site or server, the code is on
> anilumi.in/anime/<slug> under "Embed this countdown". No ads or tracking in the box. Happy to make one for any
> other show you cover.

Change the show, the slug and the example each time, and only send it to sites that cover that show.

## Don't

- Buy links, join link exchanges or "guest post" networks.
- Post the same comment in many places, or link where the page doesn't answer the question.
- Use AI to mass-write forum answers. One honest answer a day beats twenty generic ones.
